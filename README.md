# DevFolio Frontend

Frontend-only portfolio built with React, Vite, Tailwind CSS and Framer Motion.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Vercel

- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Before deployment

1. Put your resume at `public/resume.pdf`.
2. Replace `your-email@example.com` in `src/pages/Contact.jsx`.
3. Update project, certificate and social links with your real links.
